# 🛡️ КиберЩит: Беларусь

Обучающая игра о кибербезопасности: вы — стажёр управления по противодействию киберпреступности.
Next.js 16 + React 19 + PostgreSQL (Drizzle ORM) + Tailwind CSS.

---

## ⚠️ «Go Live» (Live Server) НЕ подходит!

Live Server умеет показывать только обычные HTML-файлы — поэтому вы видите **список файлов**
вместо игры. Эта игра сделана на Next.js и запускается командой `npm run dev`.

## ⚡ Самый простой запуск (Windows)

1. Установите **Node.js LTS** с https://nodejs.org (один раз, потом перезагрузите ПК).
2. Дважды кликните по файлу **`start-game.bat`** в папке проекта.
3. Подождите 1–3 минуты (первый раз ставятся зависимости) — браузер откроется сам на **http://localhost:3000**.
4. На рабочем столе игры дважды кликните **«КиберЩит.exe»**.

> macOS / Linux: в терминале `./start-game.sh`.
> База данных **не обязательна**: без неё игра работает, прогресс хранится в браузере
> (не будут работать только рейтинг и режим для школ).
> Проверьте, что рядом есть папка **`public`** — в ней картинки персонажей и шрифты.
> Если её нет, скачайте проект полностью (без неё вместо картинок будут рисованные персонажи).

## 🌍 Как выложить игру в интернет через GitHub

Есть два варианта, оба бесплатные:

| | Вариант 1: GitHub Pages | Вариант 2: GitHub + Vercel + Neon |
|---|---|---|
| Сложность | ⭐ очень просто | ⭐⭐ чуть сложнее |
| Игра, дела, кабинет, медали, сертификат | ✅ | ✅ |
| Регистрация, вход, аккаунты | ❌ (только гость) | ✅ |
| Рейтинг и режим для школ | ❌ | ✅ |
| Адрес | `https://ВАШ-НИК.github.io/РЕПОЗИТОРИЙ/` | `https://ПРОЕКТ.vercel.app` |

### Шаг 0. Загрузить проект на GitHub (нужен для обоих вариантов)

1. Зарегистрируйтесь на **https://github.com**.
2. Установите **GitHub Desktop**: https://desktop.github.com и войдите в свой аккаунт.
3. В GitHub Desktop: **File → Add local repository…** → выберите папку проекта → если спросит, нажмите **«create a repository»** → **Create repository**.
4. Нажмите **Publish repository**. Снимите галочку «Keep this code private», если хотите, чтобы GitHub Pages работал на бесплатном тарифе.
5. Проверьте на сайте GitHub, что загрузились папки **`src`**, **`public`** и **`.github`**.

> Папки `node_modules`, `.next` и файл `.env` загружать не нужно — они исключены автоматически (`.gitignore`).

### Вариант 1. GitHub Pages (самый простой)

1. На странице репозитория: **Settings → Pages**.
2. В «Build and deployment» → **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** → «Опубликовать на GitHub Pages» → **Run workflow** (или просто загрузите любое изменение).
4. Через 2–3 минуты появится зелёная галочка ✅ и ссылка вида **`https://ВАШ-НИК.github.io/РЕПОЗИТОРИЙ/`**.

Дальше каждое изменение, загруженное через GitHub Desktop (**Commit → Push**), публикуется автоматически.

### Вариант 2. Полная версия с регистрацией (Vercel + Neon)

1. **База данных:** зарегистрируйтесь на **https://neon.tech** → **Create project** → скопируйте строку подключения `postgresql://...`.
2. **Хостинг:** зайдите на **https://vercel.com** через аккаунт GitHub → **Add New → Project** → выберите репозиторий → **Import**.
3. Откройте «Environment Variables» и добавьте:
   - `DATABASE_URL` — строка из Neon;
   - `CONTACT_EMAIL` — ваш e-mail для вопросов о данных (показывается на странице `/privacy`);
   - `OPERATOR_NAME` — ваше имя или название школы.
4. Нажмите **Deploy**.
5. **Один раз создайте таблицы в базе.** В VS Code откройте терминал в папке проекта и выполните (подставьте свою строку из Neon в кавычках):
   ```bash
   npx drizzle-kit push --dialect=postgresql --schema=./src/db/schema.ts --url="строка-из-Neon" --force
   ```
6. Откройте `https://ваш-проект.vercel.app` → проверьте регистрацию и вход.

Vercel тоже обновляет игру автоматически после каждого **Push** в GitHub.

## 👤 Аккаунты

На стартовом экране: **«📝 Регистрация»** (имя, логин, пароль, согласие с правилами), **«🔑 Вход»** или **«👤 Гость»**.
При регистрации выдаётся **код восстановления** — с ним можно сбросить забытый пароль («Забыли пароль?»).
В игре кнопка **«👤»** открывает настройки: смена пароля, новый код, выход на всех устройствах, удаление аккаунта. Аккаунты хранятся в базе данных, поэтому для них нужна
полная установка с PostgreSQL (см. ниже). Без базы можно играть гостем.

## 🖥 Запуск из Visual Studio Code

Откройте терминал (`Ctrl + ~`) и выполните:
```bash
npm install
npm run dev
```
Затем откройте **http://localhost:3000** (не 127.0.0.1:5500!). Или просто нажмите **F5**.

## 🚀 Полная установка (с базой данных для рейтинга и классов)

### Шаг 0. Что установить (один раз)

| Программа | Где взять | Зачем |
|---|---|---|
| **Node.js 20 LTS или новее** | https://nodejs.org | запуск игры |
| **Visual Studio Code** | https://code.visualstudio.com | редактор |
| **Docker Desktop** *(вариант А)* | https://www.docker.com/products/docker-desktop | база данных одной командой |
| **PostgreSQL 16** *(вариант Б, без Docker)* | https://www.postgresql.org/download | база данных |

Проверка в терминале: `node -v` → должно быть `v20...` или выше.

### Шаг 1. Открыть проект
Скачайте проект (ZIP → распакуйте), затем в VS Code: **Файл → Открыть папку…** → выберите папку проекта.
Откройте терминал: **Терминал → Создать терминал** (или `Ctrl + ~`).

### Шаг 2. Установить зависимости
```bash
npm install
```

### Шаг 3. Настроить базу данных

**Вариант А — Docker (проще):**
```bash
docker compose up -d
```

**Вариант Б — обычный PostgreSQL:**
при установке задайте пароль `postgres`, затем создайте базу `app_db`
(через pgAdmin или командой `psql -U postgres -c "CREATE DATABASE app_db;"`).

### Шаг 4. Файл настроек
Скопируйте `.env.example` в `.env`:
```bash
# Windows (PowerShell)
copy .env.example .env
# macOS / Linux
cp .env.example .env
```

### Шаг 5. Создать таблицы
```bash
npx drizzle-kit push --force
```

### Шаг 6. Запустить игру 🎮
```bash
npm run dev
```
Откройте в браузере **http://localhost:3000** → дважды кликните по ярлыку **«КиберЩит.exe»** на рабочем столе.

> 💡 Можно не вводить команды: **F5** (или «Запуск и отладка» → «▶ Запустить игру»),
> а шаги 2–6 есть в меню **Терминал → Запустить задачу…**

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| `'npm' не является командой` | Установите Node.js и **перезапустите VS Code** |
| Список файлов вместо игры | Вы открыли через Go Live — используйте `npm run dev` и http://localhost:3000 |
| `ECONNREFUSED 127.0.0.1:5432` | База не запущена: `docker compose up -d` или запустите службу PostgreSQL |
| `password authentication failed` | Пароль PostgreSQL не `postgres` — исправьте его в `.env` **и** в `drizzle.config.json` |
| Порт 3000 занят | `npm run dev -- -p 3001` → http://localhost:3001 |
| Рейтинг/класс пустые | Не выполнен шаг 5 (`npx drizzle-kit push --force`) |

> Без базы данных сама игра тоже работает (прогресс хранится в браузере),
> но не будут работать **рейтинг** и **режим для школ**.
